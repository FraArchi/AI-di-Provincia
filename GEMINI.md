# AI-di-Provincia Project Guidelines

## Visual Design and Illustration Preferences

When generating illustrations for the blog (e.g., via Nano Banana), always use the established 'minimalist continuous line art' style to ensure all future artwork perfectly matches the project's aesthetic and color palette:

- **Style:** Minimalist continuous line art
- **Background:** Very light off-white gray (`#F9FAFB`)
- **Main Drawing:** A single thick black squiggly line combining a provincial/traditional/human element with an AI/tech element.
- **Accents:** A stark, minimalist geometric shape in deep burgundy red (`#8B1A1A`)
- **Keywords:** minimalist, flat vector, corporate illustration, clean edges
